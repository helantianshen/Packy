# 客户端 GUI 原型审查

2026-10-18。仅生成视觉候选，不修改生产 GUI。四组均包含同内容的浅色/深色主题；版本号、更新数量和文件版本为演示数据。

| 方向 | 结构与视觉 | 取舍 |
| --- | --- | --- |
| A 原生简洁 | 侧栏、工作区、蓝色主操作，清晰的版本与列表层级 | 易理解，视觉辨识度较保守 |
| B 游戏氛围 | 顶栏、局部原创体素风景、森林绿 | 游戏归属感强，插画资产需要后续独立制作 |
| C 暖纸编辑 | 暖白/浓咖、橙色、非对称双栏、细分隔线 | 更温和独特，需关注小窗口信息密度 |
| D 冷静夜航 | 冰灰/午夜蓝、青色、表格与底部操作区 | 信息直观，气质偏理性 |

共同功能：检查更新、版本对比、更新说明、增加/替换/移除清单、查看并安装、主题切换、后台运行。后续所选方案需要延展至检查中、下载/校验、不可取消的安装/保存、完成、失败重试与配置说明页。当前图片不证明交互实现、无障碍达标或跨平台渲染通过。

服务地址与路径保持构建内嵌；不添加账号、商店、多实例、玩家数等功能。后台 Arco 模板不在本次重设计范围内。

网络参考：

- [Modrinth App](https://modrinth.com/app/)：Mod、版本与内容结构
- [Prism Launcher](https://prismlauncher.org/)：桌面工具的信息组织
- [Fluent Color](https://fluent2.microsoft.design/color/)：明暗主题的独立色彩层级
- [Fluent Material](https://fluent2.microsoft.design/material)：跨平台可实现的实体表面

使用 Impeccable 与内置 ImageGen；完整生成提示词见 prompts.json。没有复制上述产品的图像资产。用户已选择 B「游戏氛围」，后续流程细化见 B-flow/README.md；完整流程待审查，暂不进入生产实现。
